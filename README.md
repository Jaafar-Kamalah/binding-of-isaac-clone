# binding-of-isaac-clone
A game clone I developed in C++ using SFML within a limited timeframe. The project focuses on object-oriented design principles, with an emphasis on polymorphism and a clear, maintainable architecture. A demo of the game can be seen on: https://youtu.be/SkVUqC4Mlb0.
 
> Note: Created in 2023 and later uploaded to GitHub. No Git history is available as development was done locally without version control.
